To run this project:
1. create virtual environment (python -m venv venv)
2. download from requirements.txt (python -r requirements.txt) <- make sure you actually are in the virtual environment before you do this step!
3. python run.py to download the huggingface model

Now you should be able to run it directly from the C# .exe (although it that does not work try building the C# project as well)

You do not need to run any of the python scrips from data unless you want to modify the dataset yourself.
